# HAYYIN • هَيِّن

> **L'art prophétique d'être préservé du Feu**  
> Une application web interactive basée sur le Hadith authentique rapporté par At-Tirmidhî et les enseignements du Pr. Dr. Abd al-Razzaq al-Badr (حفظه الله).

## 🌐 Démo en ligne
Accédez à l'application déployée sur GitHub Pages :  
🔗 **[https://derkitoo.github.io/hayyin/](https://derkitoo.github.io/hayyin/)**

---

## ✨ Fonctionnalités
- 📖 **Tafsir & Enseignements** : 8 points détaillés tirés des cours du Pr. Abd ar-Razzaq al-Badr.
- ⚖️ **Bilan des 4 Vertus (Tracker)** : Évaluation quotidienne de votre bienveillance relationnelle (*Qarîb, Hayyin, Layyin, Sahl*).
- 🌬️ **Pause Sérénité (Anti-Colère)** : Guide de respiration de désescalade émotionnelle, sons binauraux / Web Audio, tasbih interactif et enseignements prophétiques.
- 🧭 **Cas Pratiques & Mises en situation** : Scénarios réels avec analyse du discernement et feedback pédagogique.
